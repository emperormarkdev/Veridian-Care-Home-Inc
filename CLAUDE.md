# Veridian Care Home Website

## Project
A marketing/informational website for a care home called **Veridian Care Home**.

## Goal
A polished, premium-feeling site — the kind that looks like it was designed in Figma/Framer, not a generic template. Strong typography, thoughtful spacing, deliberate button/interaction design, and a calm, trustworthy color palette appropriate for healthcare/elder care.

## Tone
Warm, trustworthy, professional. Not clinical or cold. Not childish.

## Tech Stack
- React (functional components, hooks only — no class components)
- Vite (build tool)
- React Router (page routing)
- Tailwind CSS (styling)

## Pages / Sections
- Home
- Mission Statement
- Vision
- Services (planned)
- About (planned)
- Contact (planned)

## Status
Structure and routing are being scaffolded first. Visual design polish (typography system, color palette, spacing scale, component styling) comes after the routing skeleton is in place.
